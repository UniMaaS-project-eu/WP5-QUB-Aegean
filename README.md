# WP5-QUB-Aegean

- TACPN Generator for Aircraft Maintenance Scheduling

We develop a Python tool that automatically generates Timed-Arc Colored Petri Net (TACPN) models in TAPAAL (https://www.tapaal.net/) with `.tapn` XML format for aircraft base maintenance scheduling verification.

- Usage
  
1. Configure parameters by editing example_config.json
2. Run the generator tacpn_generator_aegean.py
3. Open in TAPAAL: The generated `.tapn` file can be opened directly in TAPAAL
